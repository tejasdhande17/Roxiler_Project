# Store Rating System - Frontend Client

This is the frontend React client for the Store Rating System.

For complete information about the project overview, database architecture, role permissions, API endpoints, and setup instructions, please see the main root [README.md](../README.md).

## 🚀 Quick Start (Frontend)

Ensure your backend server is already running on port `5001`.

```bash
# Install dependencies
npm install

# Run frontend in development mode
npm run dev
```

The app will run locally at `http://localhost:5173`.
